Meal Meat – Online Food Ordering System
Overview

Meal Meat is a web-based food ordering platform inspired by modern food delivery applications. The project allows users to browse restaurants, explore food menus, place orders, and manage their accounts through an interactive and user-friendly interface. The application also includes an admin panel for managing restaurants, menu items, and customer orders.

The main goal of this project is to provide a seamless online food ordering experience while demonstrating full stack web development concepts using Python and Django.

Installation Steps
Clone the Repository
git clone https://github.com/ChaithraBR26/Meal_mate.git
Navigate to Project Folder
cd Meal_mate
Install Required Packages
pip install -r requirements.txt
Run Database Migrations
python manage.py migrate
Start the Development Server
python manage.py runserver
